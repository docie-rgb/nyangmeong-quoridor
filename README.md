# 🐱 냥멍 쿼리도 🐶

고양이(나)와 개(AI)가 대결하는 싱글플레이 쿼리도 게임입니다.

## ▶ [지금 플레이하기](https://docie-rgb.github.io/nyangmeong-quoridor/)

> PC 브라우저 전용입니다. (모바일 미지원)

---

## 게임 방법

- 🐱 **고양이(나)** 는 보드 아래쪽에서, 🐶 **개(AI)** 는 위쪽에서 시작합니다.
- 반대편 끝 줄에 **먼저 도착하면 승리**합니다.
- 한 턴에 **말 1칸 이동** 또는 **벽 1개 설치** 중 하나만 할 수 있습니다.
- 벽은 1인당 **10개**, 하나가 2칸 길이입니다.
- 내 턴 제한 시간은 **30초**입니다. 시간이 지나면 랜덤 위치에 벽이 자동으로 설치되고, 벽이 없으면 최단경로로 1칸 이동합니다.

## 조작법

| 동작 | 방법 |
|---|---|
| 말 이동 | 강조 표시된 칸 클릭 |
| 벽 설치 | 칸 사이 홈에 마우스를 올려 미리보기 확인 후 클릭 |
| 벽 방향 전환 (가로/세로) | **R** 키 또는 **우클릭** |
| 다시 시작 | 오른쪽 **다시 시작** 버튼 |

벽 미리보기가 **주황색**이면 설치 가능, **빨간색**이면 설치할 수 없는 자리입니다.

## 규칙

- 벽 뒤로는 이동할 수 없습니다.
- **점프:** 상대 말이 바로 옆에 있으면 뛰어넘어 한 칸 더 갈 수 있습니다.
- **대각선 이동:** 상대 뒤가 벽이나 보드 끝이면 상대 말의 좌우 대각선 칸으로 이동합니다.
- 다음과 같은 벽은 설치할 수 없습니다.
  - 다른 벽과 겹치거나 십자로 교차하는 벽
  - 보드 밖으로 벗어나는 벽
  - 누군가의 목적지까지 가는 길을 완전히 막는 벽
- 벽을 다 쓰면 그 뒤로는 이동만 할 수 있습니다.

## 로컬에서 실행하기

빌드 도구 없이 정적 파일(HTML/CSS/JS)만 사용합니다.

```bash
git clone https://github.com/docie-rgb/nyangmeong-quoridor.git
cd nyangmeong-quoridor
python -m http.server 8000
```

브라우저에서 http://localhost:8000 을 열면 됩니다. `index.html`을 바로 열어도 동작합니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 구조, 고양이·개 얼굴 SVG |
| `style.css` | 디자인 |
| `game.js` | 게임 규칙, AI, 타이머, 입력 처리 |
